# حلب القديمة — Next.js + TypeScript

الواجهة تتضمن شريط بحث علوي، لوحة إعدادات قابلة للطي، لوحة شبكات مستقلة، مفتاحًا مختصرًا للألوان، وزر ملء الشاشة في المتصفحات التي تدعمه. تُطوى الإعدادات تلقائيًا على الهاتف لإتاحة مساحة للخريطة. التصميم في `src/app/interface.css` وترتيب الأدوات في `src/lib/map/interface.ts`؛ بيانات المدينة والمجسمات مستقلة عنهما.

تعرض المدينة حاليًا مباني بحدودها الأصلية وأفنيتها من GeoJSON، مع ألوان حجرية هادئة وأسقف متنوعة وخامات حجرية ونوافذ وأبواب تقريبية. توجد حواجز أسطح وتجهيزات سطحية بسيطة مولّدة لبعض المباني العادية، وليست من مسح فعلي. القلعة ومبانيها بلا نوافذ وأبواب مولّدة. الإضاءة شمسية بظلال ناعمة، وتبقى الشبكات وأدوات التحكم مستقلة عن أسلوب المباني.

## الشبكات الوهمية

توجد لوحة مستقلة أعلى يسار الخريطة بعنوان «شبكات تجريبية — بيانات وهمية». تعرض الكهرباء بأعمدة وعوارض وعوازل وأربعة أسلاك متدلية ومحولات عند بعض التفرعات، والهاتف بأعمدة خشبية وكابلات وصناديق توزيع. الصرف أنابيب مائلة مع غرف وأغطية تفتيش وأسهم جريان، والمياه أنابيب بأقطار مختلفة وصمامات ذات عجلات وأغطية سطحية. زر «معاينة المرافق عن قرب» يقرّب الكاميرا تلقائيًا. يمكن إظهار كل شبكة وإخفاؤها وطي اللوحة.

الوضع الافتراضي بخامات طبيعية وحجب واقعي: الأنابيب المدفونة لا تظهر من خلال الأرض. فعّل «إخفاء الأرض والمباني لفحص الشبكات» أو «رؤية الشبكات عبر الأرض والمباني» لفحصها. خيار «ألوان توضيحية للشبكات» يلوّن النماذج بحسب المفتاح عند الحاجة. انقر عنصرًا لعرض ارتفاعه أو عمقه الافتراضي ومواصفاته ثم «الاقتراب من العنصر». تُراعى أحجام الأنابيب والأعمدة التقريبية، لذلك يفضّل الاقتراب لرؤية التفاصيل.

تُختار مواضع بجانب الشارع، وتُقسّم المسافات الطويلة إلى بحور تقارب 32 مترًا، وتُزال نقاط الانعطاف الصغيرة مع الحفاظ على التقاطعات. يُفحص تقاطع المسارات مع مساحات المباني كل نحو 3 أمتار، وتُستبعد المقاطع المتعارضة بدل اختراع تحويلة هندسية. قد تبقى الشبكات مجزأة؛ النموذج ليس تصميمًا متصلًا معتمدًا. لا تُنشأ مسارات على تل القلعة أو الجسور والأنفاق، ولا أسلاك فوق الممرات المغطاة والأزقة الأضيق. مناسيب الصرف متسقة عند العقد ويتجه كل مقطع إلى منسوب أقل، لكنها مشتقة من دالة تجريبية وليست من مسح تضاريس أو حساب هيدروليكي.

المسارات والمواصفات والحالات مولّدة حتميًا للتجربة، وليست بيانات بنية تحتية حقيقية أو تصميمًا كهربائيًا أو هيدروليكيًا. زر GeoJSON يصدّر الوسوم `simulated` و`installation` و`depth_m` و`height_m` و`from_level_m` و`to_level_m`، مع تنبيه لكل معلم. المناسيب نسبة إلى الأرض المحلية وليست ارتفاعات WGS84؛ تبقى الإحداثيات الجغرافية ثنائية الأبعاد. يتضمن `simulation.ts` التوليد، و`utility-models.ts` المجسمات، و`utilities.ts` الواجهة. للتحقق من ثبات التوليد وحدود الخريطة واتصال العقد وتناقص مناسيب الصرف وتجنّب المباني والتصدير: `npm.cmd run test:simulation`.

خريطة ثلاثية الأبعاد بواجهة عربية RTL، مبنية على بيانات `qgis` المحلية، باستخدام Next.js App Router وReact وThree.js. مكتبة العرض تُحزم مع التطبيق؛ لا يحتاج العرض إلى CDN أو خادم Python.

## التشغيل

المتطلبات: Node.js 20.9 أو أحدث وnpm. نفّذ داخل مجلد المشروع:

```powershell
npm.cmd install
npm.cmd run data:build
npm.cmd run dev
```

افتح http://localhost:3000 واترك نافذة التشغيل مفتوحة. على الأنظمة الأخرى استخدم `npm` بدل `npm.cmd`.

نسخة الإنتاج:

```powershell
npm.cmd run build
npm.cmd run start
```

أمر `build` يعيد توليد البيانات ويبني التطبيق. للتحقق من الأنواع: `npm.cmd run typecheck`.

## الملفات والبيانات

- `src/app`: صفحة Next.js والتنسيق العام.
- `src/components/AleppoMap.tsx`: مكوّن الخريطة ودورة تشغيلها وإغلاقها.
- `src/lib/map/engine.ts`: المشهد والخامات والظلال والتنقّل والواجهة.
- `src/lib/map/types.ts`: أنواع GeoJSON والبيانات ودوال التعامل معها.
- `scripts/build.ts`: دمج `qgis` وتوليد ملفات العرض دون تنزيل.
- `scripts/qgis-source.ts`: قراءة الطبقات وإزالة التكرار والحقول الفارغة.
- `scripts/config.ts`: حدود المنطقة وموقع القلعة والإسقاط المحلي.
- `scripts/fetch.ts`: نسخة TypeScript من السكربت المحلي الذي كان في `fetch.mjs`، مع الحفاظ على حساب حدوده وخياراته؛ لا ينزّل Overpass.
- `public/old`: البيانات المولّدة التي يقرأها المتصفح.

يستخدم البناء `qgis` تلقائيًا. توجد 17,175 ميزة بعد إزالة التكرار. لتغيير حجم الخلية أو المصدر:

```powershell
npx.cmd tsx scripts/build.ts 2 qgis
npx.cmd tsx scripts/build.ts 4 old.geojson
```

عدّل `BBOX` في `scripts/config.ts` ثم أعد بناء البيانات. للاستخدام الاختياري للسكربت المحلي بحدود تلقائية أو محددة:

```powershell
npm.cmd run fetch -- 3 qgis
npm.cmd run fetch -- 3 qgis --bbox=36.188,37.145,36.206,37.172
```

هذا الأمر يكتب أيضًا إلى `public/old`. البناء العادي يستخدم الحدود المشتركة في `scripts/config.ts`. ملفات مجلد `old` القديمة ليست مصدر العرض الجديد. بعد تعديل البيانات حدّث صفحة المتصفح؛ لا تفتح ملفات HTML مباشرةً.

## التحكم

اسحب بالزر الأيسر لتحريك الخريطة، والعجلة للتقريب والابتعاد نحو المؤشر، وCtrl مع السحب أو الزر الأيمن للدوران وتغيير الميل. أزرار جانبية للتقريب والعودة إلى القلعة وتوجيه الشمال. على اللمس: إصبع للتحريك وإصبعان للتقريب والدوران.

يمكن إغلاق لوحة التحكم وإعادة فتحها، وإخفاء جميع الأسماء، وتبديل رموز الخدمات والظلال. منزلق الارتفاع يغيّر ارتفاع المباني والأشجار. ابحث عن اسم أو وسم، أو انقر على معلم لعرض بياناته وروابطه. مفتاح الألوان والأشكال أسفل الشاشة قابل للطي.

## حدود النموذج واستكشاف المشاكل

حدود المباني والأفنية والمسارات من GeoJSON. الارتفاعات المفقودة وتفاصيل الواجهات والتجهيزات السطحية تقديرية، ولا تمثّل الألوان الواجهات الأصلية بدقة. هذا نموذج بصري محسّن وليس إعادة بناء فوتوغرافية للمدينة. شكل تل القلعة وارتفاعه والسور العلوي تقديرات بصرية، وليس نموذج تضاريس مسجّلًا. بيانات الضرر وأوصافه القديمة لا تثبت الحالة الحالية. قياسات سقوف الممرات ومستويات الجسور تقديرية، وتبقى الأنفاق تحت الأرض.

إذا فقدت ملفات البيانات شغّل `npm.cmd run data:build`. عند البطء أوقف الظلال واستخدم خلية 4. إذا كان المنفذ مشغولًا جرّب `npm.cmd run dev -- --port 3001`. قد تحتاج الإنترنت أثناء تثبيت الحزم؛ بيانات العرض وخاماته محلية بعد التثبيت. تم فحص TypeScript بوضع strict، وبناء الإنتاج، واختبار العرض والتحكم والبحث والأزرار في Chrome في وضعي الإنتاج والتطوير.
